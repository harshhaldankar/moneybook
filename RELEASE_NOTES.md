What's new: Undo for balance fixes, and passbook CSV import that works

- **Balance fixes can be undone.** Matching your bank balance now adds a "Balance correction" entry instead of changing your starting balance. Tap Undo on the message, or delete the entry from Activity any time. It isn't counted as income or spending.
- **Passbook and statement CSV files import properly.** More bank formats are read, the file picker no longer greys out CSV files, and it works without internet. Passbooks that show only an amount and a balance are understood too.
- **Clearer messages** when a statement file can't be read, naming the columns that were found.
